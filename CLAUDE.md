# Notes for Claude

- `ansible/roles/containerd_apparmor` is a temporary workaround for https://github.com/ZetaTwo/infrastructure/issues/2 (Ubuntu 7.0.0-41+ kernels stack container AppArmor labels, and gosu in containerd pods hangs). It replaced node1's kernel pin to `7.0.0-38`. When `k3s_version` is bumped, or at the start of infra work, check whether k3s's containerd now includes containerd#14487: `ssh root@node1.zetatwo.dev "grep -aqF '//&unconfined,' /var/lib/rancher/k3s/data/current/bin/containerd && echo fixed"` (the role's last task reports the same thing on every apply). Once it says fixed, follow the cleanup in the issue, remove the role and this note, and close the issue.
